  DIVISOR NTC (GPIO1 / ADC1_CH0)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  3.3V
   │
   ├── 100 kΩ (R_series / pull-up)
   │         │
   │         ├──[100 nF]──┐   (filtro ADC, paralelo ao NTC)
   │         │             │
   │         └────────────►│── GPIO1 (ADC)
   │                       │
   └── NTC 100 kΩ B3950   │   (instalado no estator do motor)
             │             │
             └─────────────┘
                  │
                 GND

  Equação: R_ntc = 100kΩ × ADC / (4095 - ADC)
  Steinhart-Hart (B-param): 1/T[K] = 1/T0 + (1/B) × ln(R/R0)

  DRIVER DE RELÉ (GPIO4)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  GPIO4 (3.3V lógico)
   │
   └── 220 Ω ──► Gate IRLZ44N
                  │
                  Drain ──► Bobina relé (–)
                  Source──► GND

  Bobina relé (+) ──► 24V
  Diodo 1N4007 antiparalelo à bobina (catodo para +24V)

  Lógica do relé NC (fail-safe):
    GPIO4 = LOW  → MOSFET OFF → bobina sem energia → contato NC FECHADO → motor OK
    GPIO4 = HIGH → MOSFET ON  → bobina energizada  → contato NC ABERTO  → motor PARA
    Sem energia no ESP → GPIO4 flutuante → pull-down 10 kΩ força LOW → motor OK


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  VENTOINHA PWM (GPIO5)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Conector 4 pinos (PWM fans padrão):
    Pin 1 GND    ◄── GND
    Pin 2 +12V   ◄── LM2596 saída 12V
    Pin 3 TACH   ─── (não conectado — não monitorado)
    Pin 4 PWM    ◄── GPIO5 (3.3V lógico, 25 kHz, duty 0–100%)

  Nota: sinal PWM 3.3V é aceito diretamente pela maioria das fans
        PWM 4-pin. Nenhum nível de tensão adicional necessário.

  FITA WS2812B (GPIO9)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  GPIO9 ── 330 Ω ──► DIN (WS2812B LED 1)
                          └── DOUT ──► DIN (LED 2) ──► ... ──► (LED 5)

  VCC fita ◄── 5V (LM2596 #2 saída)
  GND fita ◄── GND comum
